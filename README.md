# Тестовый MkDocs

Демонстрационные данные; внутренних документов нет.

Локальный запуск:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.lock
mkdocs serve
```

Проверка: `mkdocs build --strict`. Готовый сайт — `site/`.
CI собирает сайт для PR и main и сохраняет артефакт на 7 дней.
После успешной сборки main сайт автоматически публикуется в GitHub Pages.
Сайт: https://rkorolev-ppm.github.io/mk-docs_demo/
Репозиторий и сайт публичные; внутренних данных здесь быть не должно.

Используются MkDocs 1.6.1 и Material 9.7.0. Material завершает поддержку
5 мая 2027 года: для постоянной корпоративной установки тему следует выбрать отдельно.

## Навигация

Левое дерево задаётся в `nav` файла `mkdocs.yml`, верхнее меню — отдельно
в `extra.top_navigation`. Шаблоны в `overrides/partials/` сохраняют полное дерево
при переходах через верхнее меню. Верхняя панель закреплена при прокрутке.

Пример четырёх уровней: Справочник → Команда → Начало работы → Первый день.
В `docs/handbook/` находятся 11 демонстрационных страниц. Весь сайт содержит
только вымышленные материалы. На узком экране левое дерево открывается кнопкой меню.

Для того же окружения, что и CI, используйте Python 3.14.
