# Первый день

Путь: Справочник → Команда → Начало работы → Первый день.

## Знакомство

Познакомьтесь с участниками вымышленной экспедиции и выберите рабочее место.

## Первое задание

- [x] Открыть документацию.
- [ ] Прочитать журнал наблюдений.
- [ ] Предложить идею.

!!! note "Четвёртый уровень"
    Верхнее меню не меняет состав дерева. Можно вернуться в галерею сверху или открыть соседнюю страницу слева.
