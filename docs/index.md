# Лаборатория документации

Это тестовый сайт **MkDocs + Material**. Здесь нет внутренних документов компании.

## Что проверить

- Поиск: введите «локальный запуск».
- Переключение светлой и тёмной темы в шапке.
- Меню слева и оглавление справа.
- [Примеры оформления](examples.md): вкладки, код и примечания.
- [Рабочий процесс](workflow.md): локальный запуск и Pull Request.

## Как устроено

Markdown → MkDocs → статические HTML/CSS/JS → веб-сервер.

Для чтения сайта Python и база данных не требуются.
